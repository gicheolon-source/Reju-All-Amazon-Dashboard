시트 ID·gid 같은 값은 `HANDOVER.json` 에 있습니다. 여기서는 **무엇을 왜 하는지**를 다룹니다.

## 1. 한 장 요약

**주간 아마존 성과를 5개국 한 화면에서 보는 대시보드입니다.**

```
https://rejuall-weekly-intl.vercel.app
```

🇺🇸 US · 🇨🇦 CA · 🇬🇧 UK · 🇦🇺 AU · 🇦🇪 AE (중동) — 상단 `MARKET` 에서 전환합니다.
화면은 Overview / Sales / Advertising 3페이지, 최근 16주를 일~토 기준으로 봅니다.

**데이터는 Google Sheets 에서 옵니다.** 스프레드시트에 리포트를 붙여넣으면 대시보드가
읽어갑니다. 서버에 따로 저장하지 않습니다.

**매주 할 일은 시트에 3가지를 채우는 것뿐입니다** (§2). 코드를 건드리거나 재배포할
일은 없습니다. 최대 5분 뒤 자동 반영됩니다.

> 구버전 `https://rejuall-gl-amz-weekly.vercel.app` (US 전용)도 살아 있습니다.
> 다국가판이 상위 호환이고 버그 수정 6건이 구버전엔 없으니, **다국가판을 쓰세요.**

## 2. 매주 하는 일

### 2-1. 매출 데이터

Seller Central → **Business Reports → Sales & Traffic by ASIN (일별)** 로 받아
각 국가 스프레드시트의 **ASIN 탭**(`Child sales_RAW_*`)에 이어붙입니다.

- 1행은 배너, **2행이 헤더, 3행부터 데이터** 구조를 유지하세요
- 헤더 문자열을 바꾸지 마세요 (컬럼을 이름으로 찾습니다)
- 열 순서는 바뀌어도 괜찮습니다

### 2-2. 광고 데이터

광고 콘솔 → **Reports → Campaign 리포트**를 **일요일~토요일 정확히 7일치**로 받아
**AD 캠페인 탭**에 이어붙입니다.

> ⚠ **기간을 반드시 일~토 7일로 맞추세요.**
> 5일치나 화요일 시작 같은 부분 기간은 중복 합산을 막기 위해 **조용히 무시**됩니다.
> 실제로 캐나다 시트에 부분 기간 5종이 들어와 전부 버려진 적이 있습니다.
> `Jul 19, 2026 - Jul 25, 2026` 형태여야 W29 로 붙습니다.

**ASIN 탭의 `Spend`·`Ad Sales` 열도 함께 채워주세요.** 이게 광고 KPI 의 기본 출처입니다
(§4 참고).

### 2-3. 주간 코멘트

각 국가 **NOTES 시트**의 해당 주차 행에 Overview / Sales / Advertising 을 씁니다.

- `Week` 값은 **`W29`** 또는 일요일 날짜 **`2026-07-19`** 형식이어야 합니다.
  `29주차` 같은 형식은 인식하지 못하고 조용히 무시됩니다.
- 줄 앞에 `-` 를 쓰면 화면에서 불릿으로 표시됩니다

### 2-4. 확인

대시보드를 새로고침합니다. **최대 5분** 걸립니다(CDN 캐시).

## 3. 화면 읽는 법

### 열리는 주차

**마지막으로 끝난 주차**로 열립니다. 진행 중인 주(예: 오늘이 수요일이면 이번 주)는
2~3일치만 집계돼 매출이 폭락한 것처럼 보이고 광고 리포트도 아직 없으므로,
기본값에서 제외했습니다. 보려면 주차 버튼에서 직접 클릭하세요.

### 지표가 어디서 오는가

| 지표 | 출처 |
|---|---|
| Total Sales · Units · Sessions | ASIN 탭 |
| **Ad Spend · Ad Sales · ACOS · TACOS · ROAS** | **ASIN 탭** (`Spend`·`Ad Sales` 열) |
| **Impressions · Clicks · CTR · 캠페인 표** | **Campaign 탭** |
| 주간 코멘트 | NOTES 시트 |

### "캠페인 리포트 기준" 문구가 보이면

ASIN 탭의 광고열이 비어 있거나 일부 날짜만 채워진 주차입니다. 그대로 두면
`Ad Spend 0 · ACOS 0.0%` 로 나와 **"광고 효율 완벽"이라는 정반대 신호**를 주므로,
Campaign 리포트 값으로 대체해 표시합니다.

**두 출처는 값이 다릅니다** — 미국에서 같은 주를 비교하니 ASIN 탭 $33,592 vs
Campaign 탭 $42,152 로 약 25% 차이가 났습니다. 집계 기준이 달라서 정상입니다.

그래서 **국가 간 ACOS 를 나란히 비교할 때는 어느 기준인지 확인**해야 합니다.
ASIN 탭 광고열을 최신까지 채우면 자동으로 ASIN 기준으로 돌아가 통일됩니다.

### 캠페인 표에 일부만 보일 때

'전체 포트폴리오' 상태에서는 광고비가 적은 캠페인을 숨겨 표를 읽기 쉽게 합니다.
**몇 개를 숨겼는지 표 위에 표시**되고, **포트폴리오나 제품을 선택하면 전부 보입니다.**

## 4. 자주 겪을 문제

| 증상 | 원인 | 조치 |
|---|---|---|
| 특정 지표가 **전 주차 0** | 리포트 헤더 문자열이 바뀜 | 헤더를 원래대로. 리포트 언어가 English 인지 확인 |
| 최근 몇 주가 **아예 없음** | 날짜 형식이 다름 (`2026. 8. 2` 등) | 시트에서 Date 열 형식 확인 |
| **ACOS 가 400% 넘게** 나옴 | `Spend` 는 채워졌는데 `Ad Sales` 가 덜 채워짐 | ASIN 탭 `Ad Sales` 열 보완 |
| **ROAS 0.00** | 위와 같은 원인 | 위와 같음 |
| 캠페인 표가 **비어 있음** | 그 주차 Campaign 리포트 미업로드 | 일~토 7일치로 받아 붙이기 |
| 광고 타입이 **전부 SP** | 광고 콘솔 언어가 현지어 | 콘솔 언어를 English 로 |
| 코멘트가 **안 보임** | `Week` 값 형식 오류 | `W29` 또는 `2026-07-19` 형식으로 |
| 화면 전체가 **DEMO** 표시 | Vercel 환경변수 누락 또는 Redeploy 안 함 | §5 참고 |

**공통점: 대부분 에러 없이 숫자만 조용히 틀립니다.** 이상하면 시트부터 보세요.

시트를 점검하는 스크립트가 있습니다 (Node.js 필요):

```bash
node _check.mjs <시트ID>          # 헤더·날짜 범위·광고열 채움 구간 한 번에 확인
node _camp.mjs <시트ID> <탭gid>   # 캠페인 리포트 기간이 유효한지 판정
node _notes.mjs <시트ID>          # 코멘트 시트 헤더·주차 키 형식 검사
```

## 5. 시스템이 어떻게 도는가 (얕게)

```
Google Sheets  ──(서비스 계정으로 읽기)──▶  Vercel 함수  ──▶  대시보드 화면
                                          주간 집계·5분 캐시
```

- **Vercel** 에 두 프로젝트가 있습니다: `rejuall-weekly-intl`(다국가), `rejuall-gl-amz-weekly`(US 구버전)
- **GitHub** 저장소 `ethan-elpapa/rejuall_gl_amz_weekly` (Private) 에 코드가 있고,
  `main` 에 푸시하면 자동 재배포됩니다
- **서비스 계정** 하나가 스프레드시트 10개를 읽습니다. 각 시트에 **뷰어 공유**가
  되어 있어야 하고, 빠지면 그 국가만 오류가 납니다

### 재배포가 필요한 경우 / 아닌 경우

| 상황 | 재배포 |
|---|---|
| 시트에 데이터 이어붙이기 | **불필요** (5분 내 자동) |
| 코멘트 작성 | **불필요** |
| 시트에서 **탭을 새로 만들어** 연결 | 필요 (환경변수 추가 → Redeploy) |
| 국가 추가 | 필요 (코드 한 줄 + 환경변수) |
| 코드 수정 | 필요 (git push → 자동) |

탭 **이름**은 바꿔도 됩니다(gid 로 찾습니다). 단 **탭을 지웠다 다시 만들면 gid 가
바뀌므로** 환경변수도 고쳐야 합니다.

## 7. 미해결 과제

### 7-1. 서비스 계정 키 교체 ★ 가장 급함

현재 키가 노출된 상태입니다. 이 키 하나로 스프레드시트 10개가 전부 열립니다.

```
Google Cloud → IAM 및 관리자 → 서비스 계정
  → rejuall-amz-us-dashboard@... → 키 → 키 추가 → 새 키 만들기 → JSON

→ Vercel 두 프로젝트의 GOOGLE_PRIVATE_KEY 를 새 값으로 수정
→ 각각 Redeploy
→ 마지막에 옛 키 삭제   ← 이 단계까지 해야 무력화됩니다
```

새 키 발급 → 반영 → 옛 키 삭제 **순서를 지켜야** 대시보드가 멈추지 않습니다.

### 7-2. ASIN 탭 광고열 보완

| 국가 | 현재 | 조치 |
|---|---|---|
| UK | `Ad Sales` 가 2026-07-19 에서 끊김 | 7/20 이후 채우기 |
| CA | 광고열이 2026-05-06 에서 끊김 | 5/7 이후 채우기 |
| AU | 광고열이 2026-06-13 에서 끊김 | 6/14 이후 채우기 |

채우면 해당 국가가 Campaign 기준 → ASIN 기준으로 자동 복귀해 US·AE 와 잣대가 같아집니다.

### 7-3. 캐나다 이전 주차 캠페인 리포트

현재 W29~W30 만 있습니다. W16~W28 을 일~토 7일치로 주차별로 받아 붙이면 채워집니다.

### 7-4. 코멘트 실제 내용

## 8. 하지 말 것

- **`data.sample.json` 을 저장소에 커밋하지 마세요.** 배포되면 무인증으로 공개되고,
  한 국가 스냅샷이 올라가면 화면이 그 국가로 잠깁니다 (`.gitignore` 에 이미 있습니다)
- **저장소를 Public 으로 바꾸지 마세요.** 집계 산출물에 실매출이 들어갑니다
- **탭 gid 를 바꾸지 마세요.** 탭 이름은 바꿔도 되지만, 탭을 삭제하고 새로 만들면
  gid 가 달라져 연결이 끊깁니다
- **부분 기간 광고 리포트를 붙이지 마세요.** 조용히 무시되어 "데이터가 안 들어왔다"는
  혼란만 생깁니다
- **이상해 보이는 값을 임의로 고치지 마세요.** 예: UK W26 의 ACOS 101.4% 는 데이터가
  온전한 상태의 실제 값입니다. 광고비 £3,430 에 광고매출 £3,381 이었습니다
